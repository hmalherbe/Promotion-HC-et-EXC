# Simulateur de reclassement — PWA Android
1. Héberger ce dossier en HTTPS (GitHub Pages, Netlify, Cloudflare Pages…). Test local : `python3 -m http.server` puis `localhost`.
2. Ouvrir l'URL dans Chrome Android → menu ⋮ → « Installer l'application ».
L'app fonctionne ensuite hors ligne. Pour changer de version, incrémenter `C` dans sw.js.
